## 〈 About

I build software that operates at the intersection of **developer tooling**, **browser engineering**, and **applied AI/ML**.

My work spans four areas: crafting published React libraries that coordinate how and when resources load; designing Chrome extensions with privacy-first architectures; engineering full-stack platforms with real signal-processing pipelines; and building multimodal ML systems for real-time threat detection.

The problems I find most interesting are the ones that live at the edge — where performance constraints meet ML inference, where browser APIs meet cryptographic pairing, where a scheduler can demonstrably cut bundle weight by nearly a third.

You'll find those ideas expressed concretely across the pinned repositories below.

### ⚡ ReactFastLoad

**Adaptive Resource-Loading Scheduler for React**

</div>

A published npm library (`react-fastload`) that coordinates **when** managed resources are handed to the browser and **in what order**. Provides five priority levels (`CRITICAL → IDLE`), shared-`IntersectionObserver` viewport preloading, concurrency capping, connection-aware back-pressure, and automatic deduplication — without intercepting network requests.

Ships `SmartImage`, `SmartVideo`, `SmartAudio`, `lazyComponent`, and `useLazyLoad`. Used in production by Hush and Musify.

### 🎚️ Hush

**Intelligent Browser Audio Control & Tab Organization**

</div>

A Manifest V3 Chrome extension that brings **per-tab volume sliders**, automatic audio conflict detection, and one-click workspace organization to Chromium. Intercepts both HTML5 media and Web Audio API contexts (via injected `GainNode`) with zero-latency. Local sound intelligence detects competing audio sources and applies ducking, pausing, or notification based on four configurable acoustic scenes (*Deep Work, Study, Entertainment, Custom*). Organizes tabs into Chrome Tab Groups with drag-and-drop reclassification.

<div align="center">

### 🎵 Musify

**Engineering-Focused Music Streaming Platform**

</div>

A full-stack music platform built around real DSP: server-side audio analysis (RMS energy, ZCR, FFT spectral centroid, onset autocorrelation tempo) over a single 8 kHz mono PCM pass. Similarity recommendations use **Z-score normalized cosine similarity** across four acoustic dimensions. Track transitions are modeled as an edge-weighted Markov graph, with idle-time `requestIdleCallback` prefetching. Priority-gated scheduling via ReactFastLoad cut the initial JS entry bundle by **~29.6%** (430 kB → 303 kB).
